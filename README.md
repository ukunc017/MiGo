# MiGo

MiGo, basit bir Kurmanci ogrenme web uygulamasidir.

## Ozellikler

- Kelime kartlari
- Gunluk ifadeler
- Mini quiz
- Gunun kelimesi

## Calistirma

`index.html` dosyasini tarayicida acman yeterli.

## GitHub Pages

Bu proje statik HTML, CSS ve JavaScript kullandigi icin GitHub Pages ile direkt yayinlanabilir.

Dosyalar:

- `index.html`: Sayfa yapisi
- `style.css`: Tasarim
- `app.js`: Uygulama mantigi ve kelime verileri
